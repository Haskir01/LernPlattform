# Lernplattform für Auszubildende

Anwendung zur Vorbereitung auf die IHK-Prüfungen AP1 und AP2
(Fachinformatiker Anwendungsentwicklung und Systemintegration).

## Technik
- Backend: ASP.NET Core Web API, Entity Framework Core
- Datenbank: MS SQL Server
- Frontend: .NET MAUI (Android, Windows)

## Funktionen
- Fragenkatalog nach Themen
- Übungsmodus mit Auswertung
- (weitere Punkte ergänzen)
